# HELD-OUT evaluation: CORD test split (money fields)

**These are held-out results. They are not comparable with the DEV SET results, which were used to build the rules.**

## Run information

- **Date (UTC):** 2026-10-22T04:01:17+00:00
- **Run number:** 1
- **Git commit:** a04a4bbcef9debf26cd64ec68c5eb7ccde79f8bb
- **Dataset:** CORD v2 test split, folder cord_test, first 30 receipts (licence CC BY 4.0)
- **Currency hint:** IDR
- **OCR / extractor:** Tesseract engine defaults at this commit: --psm 6, no line reconstruction; Pillow preprocessing (grayscale, 2x upscale of small images, autocontrast, threshold 140)
- **Tesseract:** 5.4.0.20240606
- **Python:** 3.11.9

## What was and was not evaluated

- **Evaluated:** subtotal, tax, total. These are the only fields CORD provides labels for.
- **NOT EVALUATED:** vendor, document_number, date. No ground-truth labels exist for them and none were created, so no accuracy is claimed for these fields.
- **Vision-model comparison:** not run.
- Receipts evaluated: 30 (the first in dataset file order, not hand-picked).
- A value counts as correct only if it exactly equals the label. Abstaining (flagging instead of guessing) counts as not correct, but not as wrong.
